# Счётчик очков — установка

Общий счёт для настольных игр: каждый пишет очки со своего телефона, все видят сразу.

## Что нужно

- Домен, у которого A-запись указывает на эту машину.
- Любой Linux с Docker и свободными портами 80 и 443.
- Примерно 300 МБ памяти и 1 ГБ диска.

**База данных не нужна.** Всё хранится в одном файле SQLite внутри тома Docker.

## Установка

Три файла из этой папки — `compose.yaml`, `Caddyfile`, `.env.example` — положить в любой каталог, например `/srv/score`. Дальше:

```bash
cd /srv/score
cp .env.example .env
nano .env            # вписать свой домен
docker compose up -d
```

Всё. Caddy сам получит сертификат Let's Encrypt и будет его продлевать; сертификат переживает перезапуски.

Через полминуты откройте свой домен в браузере.

## Проверка, если что-то не так

```bash
docker compose ps            # оба контейнера должны быть up, app — healthy
docker compose logs caddy    # тут видно проблемы с сертификатом
docker compose logs app
curl -s https://ваш.домен/api/health   # {"status":"ok"}
```

Самая частая причина неудачи — домен ещё не указывает на эту машину или порт 80 занят: Let's Encrypt проверяет владение доменом именно через него.

## Обновление

```bash
docker compose pull && docker compose up -d
```

Данные не трогаются. Остановка корректная, игроков не выбьет: клиенты переподключатся сами и догрузят пропущенное.

## Данные

Всё живёт в томе `score-data` и переживает `docker compose down`. Стирает историю только явное `docker compose down -v` — так делать не надо.

Резервная копия на работающем приложении:

```bash
docker exec score-app rm -f /data/backup.db
docker exec -w /app/server score-app node -e \
  "require('better-sqlite3')('/data/score.db').exec(\"VACUUM INTO '/data/backup.db'\")"
docker cp score-app:/data/backup.db ./score-$(date +%F).db
docker exec score-app rm -f /data/backup.db
```

Именно так, а не копированием файла: база работает в режиме WAL, и обычное `cp` может поймать её на середине записи.

Восстановление:

```bash
docker compose stop
docker run --rm -v score_score-data:/data -v "$PWD":/backup alpine sh -c \
  "cp /backup/score-2026-07-30.db /data/score.db && \
   rm -f /data/score.db-wal /data/score.db-shm && \
   chown 1000:1000 /data/score.db"
docker compose start
```

`chown` обязателен: приложение работает не от root, и без смены владельца база окажется недоступной для записи. Имя тома — с префиксом каталога, проверьте через `docker volume ls`.

## Как этим пользоваться

Первый вход — просто имя, без регистрации. Дальше создаёте комнату и отправляете друзьям ссылку на неё; по ссылке они попадают внутрь, введя своё имя. Хост нажимает «Начать игру» и выбирает, до скольки очков играем.

Дальше каждый со своего телефона дописывает себе очки после раздачи. Хост может исправить чужую запись, если кто-то ошибся. Отменённые записи остаются видны в журнале — чтобы за столом не спорить.
